# Stayfinder 🏡

Stayfinder is a full-stack accommodation listing web application built with the **MERN stack** and **Bootstrap 5** for UI. It allows users to explore, search, review, and post rental listings.

## 🚀 Features

- User authentication with Passport.js
- Add, edit, and delete listings
- Search functionality
- Review system with ratings
- Flash messages for success/error feedback
- Clean responsive UI with Bootstrap 5
- MongoDB Atlas for cloud data storage

## 🛠️ Tech Stack

- **Backend**: Node.js, Express.js, MongoDB, Mongoose
- **Frontend**: EJS, Bootstrap 5
- **Auth**: Passport.js, express-session
- **Utilities**: dotenv, connect-flash, method-override
